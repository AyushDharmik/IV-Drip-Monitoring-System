# IoT-Based IV Drip Monitoring System

## Overview

The IoT-Based IV Drip Monitoring System is a smart healthcare solution designed to monitor intravenous (IV) fluid administration in real time.

The system uses ESP32 and sensors to monitor drip flow and provide alerts when abnormal conditions occur. A web dashboard enables remote monitoring and future integration with mobile applications.

## Features

* Real-time IV drip monitoring
* Saline level monitoring
* Alert generation
* Web dashboard integration
* IoT-based remote monitoring
