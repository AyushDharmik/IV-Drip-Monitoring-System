# MediFlow Web Dashboard

This folder contains the web application for the MediFlow IV Drip Monitoring System.

## Features

* Admin Dashboard
* Nurse Dashboard
* Patient Monitoring
* Alert Management
* Real-Time Sensor Data Visualization
* MySQL Database Integration

## Technology Stack

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MySQL

## User Roles

### Administrator

* Manage nurses
* Manage patients
* View reports
* Monitor alerts

### Nurse

* Monitor patient status
* View IV drip information
* Receive alerts
